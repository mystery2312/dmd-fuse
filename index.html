Conçu pour l'immersion

DMD FUSE n'est pas qu'un simple afficheur. C'est le cœur visuel de votre borne d'arcade Android ou de votre setup Samsung DeX.

Grâce à son serveur Node.js ultra-léger et son interprétation chirurgicale des paquets, les animations s'affichent avec une latence quasi-nulle, laissant le CPU libre pour la physique de votre bille.

⚡ TCP vers WebSockets

Guide d'installation pas-à-pas

Ce guide est conçu pour une installation 100% Android (VPX Standalone + DMD FUSE sur le même appareil). Pas de panique si vous n'avez jamais codé, il suffit de suivre les étapes dans l'ordre !

Étape 1 : Empêcher Android de couper le système

Android est programmé pour tuer les applications en arrière-plan afin d'économiser de la batterie. Il faut lui dire de laisser notre serveur tranquille.

  • Allez dans les Paramètres de votre appareil Android, puis dans Applications.
  • Cherchez et sélectionnez l'application Termux (que nous allons installer à l'étape suivante).
  • Allez dans la section Batterie.
  • Cochez impérativement Non restreinte (ou "Aucune restriction").

Étape 2 : Préparer Termux (Le Moteur)

Termux est une petite application qui va faire tourner notre serveur en tâche de fond.

  • Téléchargez Termux uniquement depuis le site officiel F-Droid
    (Ne prenez surtout pas la version du Google Play Store, elle est obsolète et ne fonctionnera pas !).
  • Ouvrez Termux. Un écran noir avec du texte apparaît.
  • Tapez exactement cette ligne puis appuyez sur Entrée pour autoriser l'accès à vos fichiers :
    termux-setup-storage
  • Ensuite, tapez cette ligne et faites Entrée pour installer l'outil Node.js (tapez "y" si on vous pose une question) :
    pkg install nodejs

Étape 3 : Démarrer le serveur DMD FUSE

Maintenant que le moteur est prêt, on lance le script.

  • Téléchargez le fichier server.js (disponible en bas de cette page) et placez-le dans le dossier Téléchargements (Download) de votre appareil Android.
  • Retournez dans Termux, tapez cette ligne et faites Entrée pour aller dans le dossier :
    cd storage/shared/Download
  • Enfin, démarrez le serveur avec cette ligne + Entrée :
    node server.js
  • C'est bon ! Un joli message "DMD FUSE ACTIVATED" apparaît. Laissez Termux ouvert en arrière-plan.

Étape 4 : Régler VPX Standalone

Il faut dire à votre jeu d'envoyer son affichage vers notre nouveau serveur.

  • Lancez VPX Standalone pour Android.
  • Allez dans les Paramètres (Settings), puis dans la section dédiée au DMD.
  • Dans le champ "IP Address", tapez exactement 127.0.0.1 (Cela signifie "l'appareil lui-même" en langage réseau).
  • Vérifiez que le port est bien réglé sur 6789.

Étape 5 : Profitez avec l'application !

La touche finale pour afficher votre DMD sur votre Pincab.

  • Installez et ouvrez l'application DMD FUSE (le fichier .apk) sur votre écran de destination.
  • Dans la barre en haut, tapez 127.0.0.1 et cliquez sur Connexion.
  • Félicitations ! Cliquez sur l'engrenage en bas à droite ⚙️ pour personnaliser votre image de fond (Backglass) et choisir entre la résolution Standard (128x32) ou HD (256x64).
